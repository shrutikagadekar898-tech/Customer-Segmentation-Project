# Customer Segmentation Using K-Means Clustering

## Project Overview

This project focuses on customer segmentation using the K-Means clustering algorithm. Customers are grouped based on their annual income and spending behavior to identify meaningful customer segments. The project also includes an interactive Power BI dashboard for customer analytics and business insights.

---

## Objectives

- Analyze customer behavior and purchasing patterns.
- Segment customers using the K-Means clustering algorithm.
- Visualize customer segments with charts and graphs.
- Build an interactive Power BI dashboard.
- Generate business insights for targeted marketing.

---

## Features

- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Scaling using StandardScaler
- Elbow Method for Optimal Cluster Selection
- K-Means Clustering
- Customer Segment Analysis
- Interactive Power BI Dashboard
- KPI Cards and Filters

## Dataset

The dataset contains customer information, including:

- Customer ID
- Gender
- Age

The dashboard includes:

- Total Customers
- Average Customer Income

- Customer Segments
- Customer Segment Distribution
- Customer Behavior Analysis
- Customer Segment Profile
- Interactive Filters (Gender, Customer Segment, Age)

---

## Business Insights

- Customers are segmented based on annual income and spending behavior.
- Regular Active Customers contribute higher spending despite moderate income.
- High-Income Low-Spending Customers present opportunities for targeted marketing campaigns.
- Customer segmentation supports data-driven business decisions and personalized marketing strategies.

4. Open the `.pbix` file in Power BI Desktop.
